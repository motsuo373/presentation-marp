# Marp とは？

---

## Marp とは？

### Markdown でプレゼン資料を作成できるツール

- **Marpit**: 軽量な Markdown→HTML/CSS スライドデッキ変換フレームワーク
- **Marp CLI**: Markdown→HTML/PDF/PowerPoint/画像への変換ツール
- **Marp for VS Code**: リアルタイムプレビュー機能付き VS Code 拡張機能

**→ 通常の Markdown に`---`でページ区切りを追加するだけ！**

---

## Marp の特徴

### シンプルな記法

```markdown
---
theme: default
---

# スライドタイトル

内容をここに記述

---

# 次のスライド
```

**これだけでプレゼン資料が完成！**

---

## Marp の特徴

### 豊富な機能

- 🎨 **テーマシステム**: 組み込みテーマ + カスタム CSS 対応
- 📐 **ディレクティブ**: フロントマターや HTML コメントでスライド設定を制御
- 🖼️ **画像拡張構文**: リサイズ、フィルター、背景画像、分割レイアウト対応
- 🔢 **数式サポート**: KaTeX 対応
- 📱 **レスポンシブ**: 16:9、4:3 のスライドサイズ対応

## AI で資料作成の流れ

### ステップ 2: AI が Markdown を生成

AI が以下のような構造で資料を生成：

## AI で資料作成の流れ

### ステップ 3: プレビューで確認・調整

## 実際のコツ 1: プロンプト設計

### 良いプロンプトの例

```
Marpを使って「〇〇について」のプレゼン資料を作成してください。

要件：
- 10分程度の発表用（15-20スライド程度）
- 自己紹介スライドを含める
- 結論を明確にする
- スタイルは250717のshibuya-lt.mdを参考に
- セクション区切りを適切に入れる
- 2カラムレイアウトを活用する
```

**→ 具体的な要件を伝えることが重要！**

---

## 実際のコツ 2: 既存資料を参考にする

### 過去の資料をテンプレート化

- 同じスタイル（theme）を使い回す
- 同じディレクティブ設定を使う
- 同じレイアウトパターンを活用

**→ AI に「〇〇のスタイルで」と指示するだけ！**

---

## 実際のコツ 3: 段階的に改善

### 最初はざっくり、後で詳細化

1. **第 1 段階**: AI に全体構成を作らせる
2. **第 2 段階**: 各セクションの内容を充実させる
3. **第 3 段階**: レイアウトや画像を調整

**→ 完璧を目指さず、まず完成させる！**
